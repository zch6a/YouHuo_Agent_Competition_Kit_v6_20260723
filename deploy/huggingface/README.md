# 优活 Agent · 在线演示

> **注意（2026-08）**：Hugging Face 已把 Docker / Gradio Space 改为需订阅 PRO，
> 只有静态网页仍免费。本目录只在你已有 PRO 时可用。
> **免费方案见 `deploy/DEPLOY.md`（Render，连 Docker 都不需要）。**
>
> 这个 YAML 头必须留在文件第一行，否则 Space 无法识别，所以说明放在这里。

打开即用，**不需要注册也不需要登录**。每个浏览器会自动获得一份独立的演示家庭，
所以多人同时访问不会互相干扰。

| 入口 | 说明 |
|---|---|
| `/elder` | 老人端：说话办事、无忧伴陪伴、照护提问 |
| `/family` | 家属端：待办日历、高风险接力、脱敏周报 |
| `/judge` | 五分钟导览：把三项创新逐步演示一遍 |
| `/care` | 照护中心：循环事项、健康、用药、位置安全 |
| `/trust` | 可信实验室：语音共识、目的绑定策略、Saga、证明 |
| `/docs` | OpenAPI |

## 这个演示的边界

- 医院、缴费、支付、地图、消息都是**比赛沙箱适配器**，不连任何真实机构；
- 数据是演示数据，容器重启即清空，请不要输入任何真实个人信息；
- 语音合成默认使用浏览器自带引擎，不上传文本；
- 大模型不参与授权：风险等级、老人确认、家属接力、工具执行、审计都在模型之外。

完整说明与可复验测试报告见 GitHub 仓库。
