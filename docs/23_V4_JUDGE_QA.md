# v4 评委问答

## 这是不是套壳聊天机器人？

不是。大模型只负责理解自然语言；任务状态、工具 Schema、权限、审批、幂等和完成核验由确定性代码控制。断开模型也能验证核心流程。

## 为什么功能这么多不会杂乱？

所有模块围绕同一闭环：老人提出生活目标，Agent 收集信息，治理层决定权限，工具执行，Verifier 核验，家庭在必要节点接力。健康、位置、记忆都是这一闭环的不同工具域。

## 支付安全吗？

Agent 不自动扣款。演示中先生成请求，再由老人确认和家属审批；高金额可要求两位不同家属。审批绑定金额、对象和版本，修改后必须重新批准。

## 情绪识别会不会侵犯隐私？

原型只使用可解释规则，不做心理诊断。家属报告只包含数量和趋势，不包含聊天原文；紧急风险只发送最小必要提醒。

## 药品冲突可靠吗？

当前是有限演示知识库，目的在于证明安全流程和未知处理。未命中会明确提示“不代表安全”。生产版必须接权威数据库并由药师审核。

## 人脸识别做到了吗？

没有伪称真实生物识别。当前只验证相同演示图片摘要，帮助展示同意和隐私流程；真正识别需合规供应商、活体检测和独立评测。

## 50 万测试是什么？

固定种子的确定性边界、性质和状态检查，不是 50 万名老人。另有 pytest、ElderBench 和真实 HTTP 烟雾测试；真实用户研究仍是下一步。

## 鸿蒙特色在哪里？

工程提供 ArkTS 页面、位置适配、小艺 Skill/工作流/A2A/OpenAPI，架构可映射到 HarmonyOS 多设备和系统服务。当前执行环境没有 DevEco 真机，因此不虚构 HAP 已验证。
