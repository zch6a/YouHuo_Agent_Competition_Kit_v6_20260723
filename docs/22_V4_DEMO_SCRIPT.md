# v4 五分钟演示脚本

## 0:00–0:40 痛点

女儿在外地，老人会表达需求却被复杂页面、支付和记忆问题阻挡。展示老人端大字界面和家属端。

## 0:40–1:40 挂号 + 跳跃表达

老人：“优活，帮我挂骨科，孙子昨天还给我打电话了。”

优活锁定挂号，暂存孙子话题，逐项询问医院、医生和时间；正式提交前复述确认；工具回执核验后生成预约和日历。

## 1:40–2:20 情绪暂停

办事中老人说：“我一个人挺难受的，什么都不想做。”

系统不丢失任务，进入橙色无忧伴短时陪伴，不向家属发送原文。老人说“继续办事”后恢复原步骤。

## 2:20–3:05 缴费与家庭共识

老人发起高金额缴费。Agent 不自动扣款；老人确认后，女儿和儿子分别批准。同一人重复点击不计第二票。审批后若金额改变，原批准失效。数据库状态核验后才说完成。

## 3:05–3:45 健康与用药

上传体检报告 OCR 文本，系统用大白话解释“结节”等术语、提取复查日期并建议日历；明确不是诊断。录入药品计划需老人同意，展示库存预警和有限相互作用警告。

## 3:45–4:25 安全与定位

老人端发出 SOS，家属立即收到安全事件；展示精度感知围栏：边界不确定时不误报。普通月报进入摘要，减少通知疲劳。

## 4:25–5:00 技术证据

展示照护中心能力真值表、ElderBench-v4、自动化测试、50 万项审计和 HMAC 审计链。最后强调：老人自主、Agent 协助、家人兜底、结果可证。
