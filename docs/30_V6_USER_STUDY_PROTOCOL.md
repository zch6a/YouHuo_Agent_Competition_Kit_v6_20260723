# 优活 v6 老人—家属形成性用户实验协议

> 本文件是待执行协议，不是已完成实验。没有知情同意和原始记录时，不得对外宣称“老人实测有效”。

## 1. 目标

评估三项核心创新是否真的帮助老人：

1. 认知负荷治理是否减少误操作和重复解释；
2. 玻璃盒卡片是否改善对AI能力边界的理解；
3. 家属接力是否既提高安全，又不过度剥夺老人自主性。

## 2. 参与者

形成性最小目标：

- 老人不少于8人，建议覆盖60–69、70–79、80岁以上；
- 家属或主要照护者不少于4人；
- 探索阶段先招募2名老人，发现严重可用性问题后再进入正式形成性阶段。

排除与保护：无法独立表示知情同意者不进入本学生项目实验；身体不适、紧急医疗或明显心理危机时立即停止实验并联系现实支持人员。

## 3. 实验条件

每位老人完成两种条件，顺序随机：

- A：普通语音Agent交互；
- B：优活v6适老治理（一次一问、选项限制、复述确认、玻璃盒卡片）。

任务：

1. 创建一次复诊提醒；
2. 完成模拟医院挂号；
3. 发起模拟水费支付请求并让家属确认；
4. 处理一次ASR候选冲突；
5. 识别一次OCR金额冲突；
6. 中途插入闲聊后恢复原任务。

## 4. 指标

客观指标：

- 任务成功率；
- 完成时间；
- 澄清次数；
- 主持人辅助次数；
- 错误确认次数；
- 任务被中断或重复办理次数；
- 能否正确指出“谁最终做决定”。

主观指标（1–5分）：

- 容易理解；
- 感到被尊重；
- 愿意继续使用；
- 对结果有把握；
- 感到被监控或被家属控制（反向项）。

访谈问题：

- 哪句话最难理解？
- 哪个确认步骤让您安心或烦躁？
- 您希望哪些内容绝不让家属看到？
- 您希望优活什么时候自己做、什么时候找家人？

## 5. 数据最小化

- 只使用匿名参与者编号；
- 不采集身份证、真实支付信息和真实医疗账号；
- 录音必须单独征得同意；不同意录音仍可参加观察；
- 报告只展示聚合数据和经允许的匿名引语；
- 无忧伴聊天不作为实验任务，不采集私人聊天全文。

## 6. 系统支持

后端已经提供：

- `POST /v6/studies/sessions`：登记参与者、角色和同意版本；
- `POST /v6/studies/observations`：登记任务结果；
- `GET /v6/studies/summary`：生成聚合指标；
- 数据库唯一约束阻止参与者编号重复；
- 汇总接口固定附带“模拟数据不得宣传为真实老人结论”的提示。

## 7. 判定标准

推荐进入决赛主宣传的最低证据：

- B条件任务成功率不低于A；
- 高风险误确认明显下降；
- 多数老人能正确说出Agent与家属的职责；
- 至少70%的参与者认为一次一问和重复播报有帮助；
- 80岁以上参与者若表现明显下降，必须单独报告而不是用总体平均掩盖。
