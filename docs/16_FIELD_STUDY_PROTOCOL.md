# 16｜真实场景试点协议

## 目标

验证优活是否帮助老人保持自主，而不仅是提高任务速度。

## 最小可行试点

- 12–20位可自主知情同意的老人；
- 8–12位家属；
- 模拟挂号/账单，绝不收集真实密码和验证码；
- 每人完成挂号、缴费请求、提醒、混合话题和角色识别。

## 核心量表

- 任务完成率/时间/错误/求助；
- 决策自主：是否理解并自行选择；
- 目标自主：系统是否仍服务老人的目标；
- 控制自主：是否能暂停、取消、修改；
- 家庭责任：何时愿意让家属介入；
- 隐私与被监控感；
- 家属审批疲劳。

## 质性问题

- “哪一步最怕点错？”
- “哪些事情希望优活直接帮，哪些必须问您？”
- “哪些内容不希望子女看到？”
- “两位家属确认会不会麻烦，什么金额才值得？”
- “办事时插入聊天，怎样回应最自然？”

## 安全

出现疲劳、不适或真实紧急情况立即停止；研究人员不得给医疗建议；录音录像单独同意；匿名化、限定保留期和可撤回。
