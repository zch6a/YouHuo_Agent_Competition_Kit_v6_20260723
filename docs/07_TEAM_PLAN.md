# 07｜三人团队分工与里程碑

## 分工

### A 产品/商业与用户研究

- 老人和家属访谈；
- 痛点、市场、竞品与应用前景；
- 800字介绍、答辩叙事、社区合作；
- 用户实验招募和记录。

### B 视觉/交互与传播

- 老人端、家属端 Figma/ArkUI；
- 适老化无障碍检查；
- 海报、PPT、演示视频；
- 双色角色、状态反馈和动效。

### C Agent/工程

- 状态机、风险、认证、工具和数据库；
- 小艺插件/工作流；
- HarmonyOS 端联调；
- 自动化测试、部署和演示稳定性。

指导教师负责阶段评审、需求收敛、伦理与材料质量把关。

## 初赛前

- 锁定一句话创新点；
- 完成设计稿、800字文档；
- 录制可选 Demo，争取实际应用附加价值；
- 检查原创声明与文件格式。

## 复赛前

- DevEco 当前 SDK 编译 HAP；
- 小艺测试态 Agent；
- 三条核心闭环真机运行；
- 12+老人/家属试用或至少形成真实访谈证据；
- 5分钟视频；
- 故障演练：断网、重复请求、拒绝审批、API失败。

## 决赛前

- 性能和语音鲁棒性；
- 社区/养老机构试点证明；
- 现场离线备份；
- 评委问题双人交叉演练；
- 所有结论带证据，不夸大真实接口与医疗能力。
