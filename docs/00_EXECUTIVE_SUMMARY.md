# 优活 Agent v4.0 执行摘要

## 项目定位

“优活”是面向独居老人的可信生活智能体。它将老人自然语言中的办事需求转化为可追踪任务，由 Agent 完成信息查询、渐进式填表和低风险步骤；支付、身份和敏感操作由老人确认或家属接力；执行结果必须经过权威状态核验后才向老人播报成功。

项目同时提供橙色“无忧伴”隐私陪伴角色。两种角色通过颜色、文字、声音提示和权限边界明确区分：优活实名留痕，无忧伴默认不把聊天全文提供给家属，只输出不含隐私细节的趋势报告。

## 八大能力域

1. 全语音挂号、缴费、提醒和表单引导。
2. 优活/无忧伴双角色与情绪感知任务暂停。
3. 老人确认、家庭接力、双家属共识和防篡改审计。
4. 实物位置、亲友档案和同意优先记忆。
5. 体检报告解释、复查提醒和健康事件归档。
6. 无交互预警、SOS、精度感知围栏和生活 POI。
7. 用药计划、服药记录、库存预测和有限相互作用演示。
8. 循环事务、情绪周报、月度报告和照护关系图。

## 核心创新

- **刚性任务锁 2.0**：主任务不会因跳跃话题丢失；明显低落时可安全暂停，陪伴后恢复。
- **可信自主权包络**：根据风险、金额、歧义、敏感性和可逆性决定谁确认、谁执行。
- **证明式完成**：工具回执、数据库状态、参数和审批摘要一致才完成。
- **同意优先记忆**：家属只能提出，老人本人决定激活和共享。
- **不可信文档防火墙**：OCR/VLM 文本不拥有工具权限。
- **注意力预算**：紧急事件立即通知，普通事件合并成摘要。

## 工程交付

工程包含 FastAPI 后端、老人端/家属端/照护中心 Web Demo、HarmonyOS ArkTS 工程壳、小艺 Skill/工作流/A2A/OpenAPI、MCP 边界、ElderBench-v4、自动化测试、大规模审计、比赛文案和答辩材料。

## 可信边界

本包是竞赛原型。医院、支付、地图、推送和身份平台均为沙箱或适配层；药品与医疗功能不提供诊断；“人脸”仅为相同演示图片摘要匹配；HarmonyOS 尚需 DevEco Studio 和真机联调。自动化结果不能等同于真实老人临床或生产验证。
