# 优活 v6 五分钟决赛演示脚本

## 0:00–0:30 痛点

老人知道自己要办什么，却被复杂页面、语音识别错误、高风险支付和子女不在身边卡住。优活不是替老人掌控生活，而是让老人保留决定权。

## 0:30–1:15 语音不确定性

输入两个ASR候选：“确认办理缴费”与“取消不要缴费”。系统不猜测，明确提示候选冲突，并要求老人重新说“确认办理”或“取消办理”。

展示点：N-best共识、紧急优先、风险阈值。

## 1:15–2:00 认知负荷治理

老人说：“帮我交水费。”系统只播报一项关键金额，不一次抛出四个选项；要求老人复述金额，字号和语速根据档案调整。

展示点：一次一问、选项上限、teach-back。

## 2:00–2:45 文档冲突防火墙

权威账单返回68.40元，拍照OCR却识别成9999.99元。安全预演显示冲突字段被剥离，系统暂停并要求重新核验。

展示点：不可信文档不能控制副作用；可信与不可信值也不能静默合并。

## 2:45–3:30 家庭接力与完成证明

老人确认后，女儿端收到绑定金额与账单的请求。女儿确认，系统查询模拟账单权威状态，只有状态一致才播报“已完成”。

展示点：老人自主、家属接力、审批快照、防重复、权威状态核验。

## 3:30–4:10 玻璃盒信任卡

页面显示：系统听到了什么、使用了什么来源、谁有最终决定权、是否可撤销、下一步是什么。强调这不是公开模型思维，而是公开用户真正需要的依据。

## 4:10–4:35 鸿蒙全场景

切换到HarmonyOS老人端与家属端，展示决赛导览页、端A2A任务状态和家属确认。真机版本必须使用队伍实际录制素材，不用Web页面冒充。

## 4:35–5:00 证据与边界

快速展示：227项自动化测试、VoiceBench 800/800、v6确定性断言500,000/500,000、既有v5断言1,000,000/1,000,000、真实Uvicorn负载和用户实验面板。

最后一句：

> 优活的创新不是让AI替老人决定，而是让老人用更少负担作出更清楚、更安全、可验证的决定。
