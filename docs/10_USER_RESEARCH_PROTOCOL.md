# 10｜真实用户研究协议

## 目的

验证真实痛点、交互理解、任务效率、信任与隐私边界，不用于医疗诊断。

## 参与者

- 60岁以上、能自主知情同意；
- 覆盖独居/与配偶居住、不同手机熟练度；
- 家属或照护者配对参与；
- 排除正在发生紧急医疗状况者。

## 伦理与隐私

- 书面/口头易懂知情说明；
- 可随时退出且不影响权益；
- 不收集真实银行卡密码、验证码或医疗敏感文件；
- 使用模拟账单与预约；
- 录音录像需单独同意；
- 研究数据匿名编号、加密存储、限定保留期。

## 访谈问题

1. 上次需要子女帮助完成的手机事务是什么？
2. 哪一步最害怕出错？
3. 更愿意自己确认还是让家属确认哪些事项？
4. 办事与陪伴分角色是否容易理解？
5. 哪些聊天内容不希望家属看到？
6. 逾期多久通知家属合适？

## 可用性任务

- 语音挂号；
- 查水费并生成家属请求；
- 确认待办完成；
- 办事中插入聊天；
- 切换无忧伴；
- 取消一个任务。

## 观察记录

- 是否理解当前模式；
- 是否知道下一步要说什么；
- 是否听懂复述金额/时间；
- 是否找到取消和求助；
- 是否产生被监控感；
- 研究员介入次数和原因。

## 停止规则

参与者出现疲劳、焦虑、明显不适或要求停止时立即结束；涉及真实诈骗/健康风险时停止实验并建议联系可信家属或专业渠道。
