# 生产与真机接入缺口

## 尚需正式完成

- DevEco Studio SDK 对齐、HAP 编译、签名、权限弹窗与真机测试。
- 小艺 Agent/Skill/A2A 正式账号创建与审核。
- Account Kit/OAuth、Push Kit、Location Kit、地图导航和系统级 ASR/TTS。
- 医院号源、政务、水电燃气、支付和身份认证的合法 API 或官方沙箱。
- 云数据库、KMS、密钥轮换、备份、灾备、监控、限流和渗透测试。
- 数据保护影响评估、监护/授权关系核验、社区合作与应急责任边界。
- 方言、弱网、噪声、低端设备、无障碍和真实老人研究。
- 权威药品数据库、专业医学审核和真实生物识别供应商。

## 不应在答辩中宣称

- “已经接入所有医院/缴费平台”。
- “能控制所有品牌手机和任意第三方 App”。
- “自动诊断疾病或保证药品组合安全”。
- “真实人脸识别已经生产可用”。
- “50 万次审计等于 50 万名老人实测”。
- “任何环境绝对零错误”。
