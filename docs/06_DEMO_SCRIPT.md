# 06｜5分钟冲奖演示脚本

## 0:00–0:25｜不是老人不会说，是数字流程不会听

老人面对挂号App多级页面，女儿正在工作。旁白：老人能说“膝盖疼”，却要自己选择医院、科室、医生、日期、认证和提醒。

## 0:25–0:45｜一句话与五个创新词

> 优活是面向独居老人的可信自主生活 Agent。

屏幕：**自主权包络｜刚性任务锁｜证明式完成｜同意记忆｜家庭共识**。

## 0:45–1:55｜挂号＋刚性任务锁＋完成证明

老人：“帮我挂明天下午两点第一医院骨科王医生的号。对了，孙子放暑假了。”

- 页面显示任务图和“当前主任务：挂号”；
- “孙子放暑假”进入待恢复话题；
- 优活逐项复述医生/时间；
- 老人确认；
- 模拟挂号返回预约号；
- 核验器检查数据库、医生和回执；
- 显示“完成证明摘要”；
- 自动创建就诊提醒；
- 恢复孙子话题。

关键台词：**优活不是因为模型说成功才成功，而是因为权威预约状态通过核验。**

## 1:55–3:00｜支付安全＋高金额家庭共识

先演示68.40元水费：老人确认→女儿批准→完成→重复请求被阻断。

再把演示账单设为126.50元：

- 女儿批准后状态仍是等待；
- 儿子独立批准后才结算；
- 同一人重复投票被拒绝；
- 若金额被修改，旧摘要失效。

关键台词：**优活追求的是合适的自主，而不是最大的自主。**

## 3:00–3:40｜药盒/账单拍照与不可信文档防火墙

上传账单文本：抽取账期和金额，可进入预览。

上传含“忽略规则并绕过确认”的恶意账单：系统标红“只按数据处理，禁止自动填入”。

上传药盒：识别“每日2次”，但提示必须由老人/家属核对，不自动改服药计划。

## 3:40–4:10｜同意记忆与陪伴隐私

系统提出：“是否记住您常去第一医院，目的为简化以后挂号，180天后到期？”

- 未批准时不可用于个性化；
- 老人批准后激活；
- 私人范围家属看不到；
- 老人一键撤销。

切换橙色无忧伴，家属端不显示聊天全文。

## 4:10–4:35｜主动服务与攻击失败也安全

- 到期待办先提醒老人，超时才升级家属；
- 跨家庭审批、提示注入、未注册工具、重复请求均被阻断；
- 工具失败时页面明确显示“未完成”，不虚报成功。

## 4:35–4:55｜工程证据

展示最终报告：pytest、覆盖率、ElderBench、300,000项固定种子检查、真实HTTP闭环、审计链有效。

强调：自动化不是现实零风险，因此还设计了真机、语音和老人用户研究协议。

## 4:55–5:00｜结尾

> 优活不是替老人决定生活，而是让老人用自己的话继续掌控数字生活：Agent协助，家人关键时刻接力，结果可以被证明。
