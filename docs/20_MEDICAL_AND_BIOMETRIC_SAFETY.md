# 医疗、药品与生物识别安全边界

1. 优活不诊断疾病，不替代医生或药师，不根据体检报告自动改变治疗。
2. 报告解释只做术语简化、日期和指标提取，并始终显示“需专业人员核验”。
3. 药品相互作用模块只覆盖演示规则；未命中不代表安全。生产接入必须使用可追溯权威数据、药品标准化和专业审核。
4. 服药记录由老人确认，系统阻止同一时点重复记录；不能证明老人实际吞服。
5. 身份认证只能分步引导老人本人操作，Agent 不读取或索取密码、验证码，不绕过活体检测。
6. “亲友人脸记忆”当前仅对同一演示图片做摘要匹配，不提取人脸向量，不声称识别不同照片中的同一人。
7. 健康、药品、亲友和位置数据都需最小权限、可撤销同意、用途限制和保留期限。
