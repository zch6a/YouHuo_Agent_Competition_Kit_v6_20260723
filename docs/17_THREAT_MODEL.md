# 17｜系统威胁模型

## 资产

- 老人身份、家庭关系、任务和提醒；
- 支付/预约授权；
- 陪伴隐私；
- 记忆和偏好；
- 工具能力与令牌；
- 审计完整性。

## 信任域

1. 老人/家属客户端；
2. 身份与API网关；
3. 生成式语言层；
4. 确定性治理层；
5. 外部工具/MCP/小艺插件；
6. OCR/VLM文档；
7. 数据库与审计。

生成式层、外部工具和文档均不属于权威域。

## 主要攻击路径

- 直接/间接提示注入；
- 伪造家属、跨家庭访问；
- 审批后换金额/对象；
- 重放与并发重复副作用；
- 工具描述投毒和未注册工具；
- 模型把陪伴内容转成办事依据；
- 自动保存敏感记忆；
- 前端XSS、日志泄漏、密钥泄漏；
- 工具成功文本与真实状态不一致。

## 控制优先级

1. 能力最小化；
2. 数据/指令分离；
3. 显式人类同意；
4. 权威状态核验；
5. 幂等与原子性；
6. 家庭作用域；
7. 审计和检测；
8. 可解释失败与人工接管。

## 剩余风险

- 规则检测不能覆盖所有语义注入；
- 真实ASR、视觉模型和第三方API会引入新错误；
- 家属账号本身可能被盗；
- 多人共识会增加延迟；
- 紧急规则存在漏报/误报；
- 当前SQLite原型不适合多节点生产。
