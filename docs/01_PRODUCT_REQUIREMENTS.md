# 01｜产品需求文档（PRD）

## 1. 用户

### 主要用户

独居或半独居、能表达需求但不熟悉复杂手机流程的老人。

### 次要用户

异地子女、其他经老人授权的家庭照护者。

## 2. 核心用户任务

| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| U1 | 老人说“帮我挂号” | 系统一次只问一个缺失字段，正式提交前明确复述 |
| U2 | 老人说“帮我交水费” | 老人确认后仍不扣款，家属批准准确摘要后才结算 |
| U3 | 子女创建复诊待办 | 老人端收到，逾期未确认才升级家属 |
| U4 | 老人在办事中突然聊孙子 | 主任务继续，话题暂存且完成后可恢复 |
| U5 | 老人切换无忧伴 | 视觉、语音、文字同时提示；陪伴不能调用高风险工具 |
| U6 | 陌生家属试图审批 | 返回拒绝，权威状态不变化 |
| U7 | 同一请求重复发送 | 相同载荷重放同一结果；不同载荷返回冲突 |
| U8 | 老人疑似遇到诈骗/紧急情况 | 立即显示安全提示并最小必要通知家属 |

## 3. 功能需求

### F1 语音优先、多模态兜底

- 语音识别为主；
- 大字文本、按钮为备选；
- 所有关键状态必须语音播报；
- 允许“再说一遍”“暂停”“取消”“问家人”。

### F2 双 Agent

- 优活：实名办事、状态化、留痕；
- 无忧伴：陪伴、默认私密、无高风险工具；
- 活跃任务未结束时不能静默切换陪伴。

### F3 任务状态机

```text
COLLECTING
→ AWAITING_ELDER_CONFIRMATION
→ [HIGH] AWAITING_FAMILY_APPROVAL
→ EXECUTING
→ COMPLETED / FAILED / CANCELLED
```

### F4 风险等级

- L1 信息：查询；
- L2 低风险：提醒、日历；
- L3 敏感：正式挂号、取消预约；
- L4 高风险：支付、身份信息、认证辅助。

### F5 家庭协同

- 家庭账号绑定；
- 权限不从请求体传入；
- 高风险审批显示事项、金额/对象、时间和版本摘要；
- 家属可拒绝并填写原因；
- 逾期升级可配置。

### F6 隐私

- 办事记录保留必要操作字段；
- 无忧伴不向家属展示全文；
- 日志脱敏手机号、身份证、银行卡和验证码；
- 紧急通知只发送风险类别和联系建议。

## 4. 非功能需求

- 可用性：老人每轮只需处理一个选择；
- 安全：高风险不可仅靠 LLM 决定；
- 可解释：每一步显示“正在做什么、为什么要确认”；
- 可恢复：网络/工具失败不宣称成功；
- 可测试：每项核心机制都有自动化不变量；
- 可移植：工具适配层可替换成正式平台 API。

## 5. 不做事项

- 不自动读取或泄露短信验证码；
- 不代替老人完成人脸认证；
- 不绕过第三方 App 权限；
- 不提供医疗诊断；
- 不把陪伴对话当作家属监控数据；
- 不在没有官方接口时宣称真实支付/挂号生产接入。
