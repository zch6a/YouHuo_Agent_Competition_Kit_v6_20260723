# v4 评测计划

## 目标

证明系统在已实现的竞赛沙箱范围内具备：任务正确性、权限安全、隐私最小化、异常恢复、重复保护和结果可验证性。

## 评测层级

### 1. 单元与 API 测试

覆盖任务路由、审批、任务锁、情绪暂停、循环事务、实物记忆、健康、用药、位置、SOS、跨家庭隔离、HMAC 审计链、OpenAPI 和静态页面。

### 2. ElderBench-v4

120 条固定样例，覆盖六类：情绪、循环事务、位置安全、医疗报告、药品安全和治理边界。评价是否得到预期标签、策略或警告。

### 3. 大规模确定性审计

50 万项固定种子检查，包含：

- 100,000 项循环规则和月末边界；
- 100,000 项情绪标签、隐私和通知策略；
- 100,000 项位置/精度/围栏性质；
- 75,000 项药品库存与相互作用边界；
- 50,000 项医疗日期、指标和 FHIR 结构；
- 74,000 项治理 Schema、权限和不可信输入；
- 1,000 项有状态幂等闭环。

这些不是 50 万名真实老人，也不是 50 万次第三方生产调用。

### 4. 真实 HTTP 烟雾

启动 Uvicorn，通过 HTTP 完成健康检查、双家属支付、同意记忆、情绪暂停恢复、循环事务、医疗报告、用药、围栏、SOS、月报和能力真值表。

### 5. 线下用户研究

自动化不能替代真实用户。建议至少完成：

- 老人及家属知情同意；
- 普通话/方言、噪声、重复表达；
- 任务完成时间和点击次数；
- 角色区分正确率；
- 误报/漏报、通知疲劳和主观信任；
- 发生风险时立即停止，不做医疗实验。

## 指标

任务成功率、状态一致率、高风险拦截率、重复副作用率、越权阻断率、任务恢复率、隐私泄露率、误报/漏报、完成时间和 SUS/可理解性评分。
