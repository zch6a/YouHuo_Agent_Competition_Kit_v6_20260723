# 2.0.2 修复说明（2026-09-27）

- 老人端和小优对话支持按住录音、松开转文字；浏览器端使用自己的后端识别，不再只依赖浏览器的识别服务。录音不落盘，识别文字不会自动发送。
- 按住期间显示正在听；松手、滑出取消、切换窗口或关闭页面均停止录音；权限拒绝、空录音和超时分别提示。最长20秒。
- 中文识别使用官方 sherpa-onnx Paraformer small int8 模型（79 MB），进程实测约177 MB。首次使用下载并校验模型，云服务重启后可能重新准备。
- 模型出处：https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-paraformer/paraformer-models.html#csukuangfj-sherpa-onnx-paraformer-zh-small-2024-03-09-chinese-english
- 在3种系统合成声音、8句提醒/时间/数字测试中，不计标点，24/24句文本一致。这不是实人准确率；噪声、口音、药名和专有名称仍需核对。未在用户手机上测过真实麦克风。
- 提醒与记忆使用共用的小页面：提醒添加/修改/完成/取消，记忆提议/本人同意/拒绝/忘记；家人不能批准记忆或替老人标记完成。
- 安装包和PWA图标更换为用户提供的优活图标。安卓版本2.0.2，versionCode=4，与旧包同一签名。
- 服务器仍是免费演示部署：休眠与重启时的数据持久性限制未改变。

验证：30项后端测试，录音会话/取消/权限/重采样单元测试，浏览器中的跨端提醒与记忆操作。实际手机兼容性不在已验证范围。
