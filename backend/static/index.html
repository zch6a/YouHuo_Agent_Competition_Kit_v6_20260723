优活 · 一本给家人的本子

让家，更近一点。

不是多一个 App，是少一点担心。

先告诉我们，今天您是谁

请选一个身份，开始

我是老人 给我自己用

大字、大按钮。说一句话就能记一笔账， 找不到路就让孙辈看见我的位置。

进入老人端 →
我是家人 陪爸妈用

一处看见爸妈的位置、用药、记账； 紧急时一键拨过去，不用再翻通话记录。

进入家人端 →

也可以直接打开某一套界面

三套设计办的是同一件事，不同的只是版式和美术。前两套是手机版，第三套是网页端。

老人端设计一 → 现在这一版，大字、大按钮。 老人端设计二 → 另一套版式与美术。 家人端设计一 → 今天、待办、我的三屏，照护另开一页。 家人端设计二 → 今天、待办、照护、我的，四屏合在一页。 老人端设计三 → 网页端。左边今天的事，右边说话办事。 家人端设计三 → 网页端。家人端和照护中心在同一页切换。
