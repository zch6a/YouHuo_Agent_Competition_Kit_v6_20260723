把小优装进手机

优活 2.0.2 · 安卓公网体验版
一个 App，老人端和家人端两个模式。

下载优活安装包

  1. 手机连接 Wi-Fi 或移动网络即可，无需电脑开机。
  2. 点上方下载，完成后打开 APK，按手机提示允许本次安装。
  3. 打开桌面的“优活”。在“我的”中切换老人端或家人端。
  4. 首次使用语音时允许麦克风权限；按住话筒说话，松开后自动转成文字，核对后发送。
