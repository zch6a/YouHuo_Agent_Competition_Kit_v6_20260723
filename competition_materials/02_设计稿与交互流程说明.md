# 设计稿与交互流程说明

## 老人端

- **蓝色优活**：顶部持续显示“正在办什么、进行到哪一步、下一步要说什么”。
- **橙色无忧伴**：明确播报已进入陪伴模式，不允许调用支付、身份等高风险工具。
- 大字体、大按钮、语音与文字双通道；颜色不是唯一提示。
- 关键按钮：说话、暂停、继续、取消、求助。

## 家属端

- 今日需接力事项、待确认支付、超时任务、SOS、月报。
- 可创建一次性或循环事务；不能默认读取陪伴聊天全文。
- 远程协助仅限“查看当前步骤、语音指导”等老人授权能力，不允许后台接管支付。

## 总流程

```text
老人语音
→ 办事/陪伴/紧急路由
→ 主任务锁定与缺失信息收集
→ 风险、歧义、可逆性和权限判断
→ Agent dry-run
→ 老人确认/家属接力/双家属共识
→ 工具执行
→ 最终状态与关键字段核验
→ 播报结果、写入日历/健康档案
→ 恢复暂存话题
```

## 情绪低落流程

```text
办事中检测到明显低落
→ 保存当前步骤
→ 切换橙色短时陪伴
→ 原始聊天不进入家属周报
→ 老人说“继续办事”
→ 恢复原任务
```

## 安全原则

- 支付不自动扣款；身份认证只引导本人。
- OCR、图片文字和模型输出均视为不可信。
- “模型说成功”不算完成，必须有回执和数据库状态证明。
- 老人可拒绝、撤销和删除记忆；家属建议需老人批准。
