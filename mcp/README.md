# 可选 MCP 互操作层

核心竞赛演示不依赖 MCP。该目录展示如何把优活的只读查询、任务计划和工具预览暴露为结构化工具，同时保持安全边界。

## 原则

- 默认只读和 dry-run；
- 任何写操作仍由优活后端认证、风险策略和人类同意控制；
- MCP客户端传入的文本和工具描述都不获得系统权限；
- 不把访问令牌放入模型上下文；
- 为每个工具声明风险、可逆性和确认要求；
- 服务端记录调用来源和审计事件。

`optional_fastmcp_server.py` 只有安装兼容的稳定 MCP Python SDK 后才运行，未列入核心 requirements，避免影响离线复现。
