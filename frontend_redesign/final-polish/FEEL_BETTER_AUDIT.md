## 这一轮最重要的一件事：三条「声明了，但从来没画出来」

这三条彼此独立地被发现，而它们是**同一个机制**：

| | 声明 | 实际 | 谁赢了 |
|---|---|---|---|
| Tab 当前项加粗 | `.tab.is-current svg { stroke-width: 2.3 }` | 和 1.8 **墨量完全相同**（2698 vs 2698） | `<symbol>` 自带的 `stroke-width="1.8"` |
| 关掉斜杠零 | `--numeric-plain: "zero" 0, "tnum" 1` | 墨量 9301 → 9301，**一点没变** | 这一版 Atkinson 的斜杠是字形轮廓，不是 OpenType 可替换字形 |
| 图标墨色是黑的 | 审计读到 `fill: rgb(0,0,0)` | 画出来是 `currentColor` | `<symbol>` 自带的 `fill="none" stroke="currentColor"` |

前两条是**产品**在骗自己（写了规则，效果不存在），第三条是**仪器**在骗自己
（读了一个不参与绘制的值）。三条共用一句话：**`<use>` 影子树里，元素自身的表现属性
赢过从宿主继承下来的值。**

第一条的代价不只是"图标细一点"。`pages.css` 那一段注释写着：当前 Tab 有两条非颜色
通道（3px 帽 + 图标变粗），所以状态在单色屏和最常见的色觉障碍下都还在。
**其中一条一直是死的**——声称的冗余只有一半，而这是一条无障碍承诺。

而守着它的那条测试（`test_tabbar.py`）绿了很久，因为它 `re.search` 的是
**选择器字符串在不在**。同一个函数的 docstring 上面三行正好写着：
「选择器存在不等于指示条存在」。它对指示条那一半执行了这条纪律，对图标那一半没有。

修法与复验：

```
sprite 删掉 5 处 stroke-width，线宽只由 CSS 出
→ 真实页面光栅化：手机 +18.6% 墨，宽屏 +31.6% 墨（改前 0%）
→ 测试判据换成「CSS 有加粗规则 **且** sprite 不许自己钉死线宽」
```

**我自己也在这条上错了一次**：contrast 那个误报，我第一版把
`.tab-icon { fill: none; stroke: currentColor }` 写进了 `@media (min-width: 761px)`，
只有宽屏拿得到——而审计恰好在宽屏量，所以它绿了。Lane A 指出来之后重新用
括号计数确认，才发现第二版又落进了 `@media (max-width: 760px)`，正好是反的另一半。
**同一个文件、同一个属性、连着两次放错媒体查询**，两次都"看起来对"。
最后写了一个数括号的小工具来判断作用域，不再靠缩进看。

### 引号：47 : 8，然后是 39 : 0，方向相反

前端可见文案里 `「」` 47 处、`“”` 8 处；后端**反过来**，用户可见的几乎全是 `“”`。

这两边的字**出现在同一个聊天窗口里**：她的气泡由前端渲染，优活的回话由后端返回。
一屏之内两套引号，正是既有那条中文排版闸门的 docstring 说的
「一段文字里两种引号并存，是『文案没过排版』最典型的痕迹」——而那条闸门只认
**ASCII 直引号**，看不见这一对。

统一到 `「」`：13 个文件、106 个引号字符。**全部行为测试照旧通过**，
只有 4 条源码指纹红（那正是它们的职责）。

## 拒绝

### B-15 · 宽屏上 0×0 的 Tab 仍在焦点序 —— **FalsePositive**

Lane B 报 `/care` `/family` 宽屏下三个 `a.tab` 是 0×0 而 `display` **不是** `none`，
判为「键盘用户会撞到三个看不见的停靠点」。

实测推翻：

```
nav 自己：display=none   checkVisibility()=False
子元素   ：display=inline（这是它**自己**声明的值）  可见=False  0×0
40 次 Tab 键，焦点落进这条栏 0 次
```

`getComputedStyle` 对一个 `display:none` **祖先**下的元素，返回的是这个元素自己的
display，不是 none。拿它判可见性，会把整棵被藏起来的子树都当成可见。

**这是本轮第三次同一类仪器错误**（另两次：SVG 宿主的 `fill` 不参与绘制；
我自己把 CSS 写进只覆盖一半视口的媒体查询）。共同点是——**读到的那个值，
不是决定结果的那个值。**

### A-01 · 关掉斜杠零 —— 采纳诊断，**暂缓实施**

Lane A 证明了 `"zero" 0` 对这一版 Atkinson 无效（墨量不变，字形中心有墨），
诊断是对的，而且顺带发现 `tokens.css` 与 `pages.css` 两段注释描述了一个**不存在的效果**。

但它建议的修法是**给所有纯数字位换一套字体**。那会改变全站每一个数字与相邻汉字的
字重和字宽关系，Lane A 自己也标了「Risk：中……必须目视复验，不能只跑闸门」。
Phase 5 会重拍全尺寸截图并做视觉评分——**这条留到那时候连图一起看**，
现在改等于在没有对照图的情况下动全站数字。已记入 `KNOWN_ISSUES.md`。

### B-14 · `/stage` 17 个 40px 控件 —— **Not Applicable**

`/stage` 是 `data-surface="platform"`，鼠标场景，而那处 CSS 注释写明是**有意**压低的
（「它们不是产品的一部分，视觉上必须比手机里的任何东西都安静」）。
Lane B 自己也标注了这一点。不改。

### B-17 · `border` + `shadow` + `background` 三者同时表达层级 —— **推到 Phase 5**

43 个元素 22 种类型，最大一族是 `.panel`。Lane B 量出背景在 `--bg` 上只有 1.081:1 的
分离度、而 border 对 surface 是 1.28:1，据此判 border 与 shadow 是重复的那一对。

诊断可信，但「去掉哪一个」是纯视觉判断，且 `.panel` 是全站最基础的容器——
和 A-01 一样，留到 Phase 5 有对照图的时候做。

### B-08 / B-09 · 深色模式下 surface 阶梯反向 —— **推到 Phase 5**

浅色里子元素比父亮（凸起），深色里子元素比父暗（凹陷），同一个嵌套的高低关系相反；
`--surface-3` 相对 `--bg` 的明暗符号在两个模式之间翻转，幅度还差 5 倍。

这是**设计系统级**的判断，不是一处 bug。改它等于重排整套表面令牌，必须连图看。
Lane B 附带纠正了一处：任务书里写的 `--surface-1` 在四层 CSS 里**不存在**，
实际梯级是 `--surface` / `-2` / `-3`。

### A-06 · 老人端两个 Tab 图标语义对不上 —— **推到 Phase 5**

「记录」用的是爱心托举（`#tab-care`），而同一个图标在 `/family` `/care` 上表示
**「照护」**；「我的」用的是盾牌+对勾（安全/已验证），不是「我的习惯」。
同一个图标在同一个产品里表示两件事，对认知在下降的老人是实打实的成本。

诊断成立，修法（往 sprite 加两个 symbol）也不违反「不许 silent delete」。
但新画两个图标要和现有五个在线宽、圆角端点、视觉重量上对齐——这是画图，
放进 Phase 5 图标语言那一轮一起做。

## Lane B 自己推翻的两条（值得记下来）

**B-18**：首轮报了 7 对可点元素与固定 Tab 栏真重叠，差点是个 P1。复核发现它滚的是
`document.scrollingElement`，而这一屏真正的滚动层是 `.elder-panel`——滚对之后
重叠 19px → **0**。这正是 Phase 0 那条纪律的反面用法：脚本能滚的容器和手指能滚的
容器不是同一个，两个方向都会出错。

**B-19**：圆角同心命中 17 组候选，逐组复核后**可见的错圆 0 组**——16 组的内角落在外角
弧线区之外（两个圆根本不照面），唯一相接的那组两边同色、无边框，看不见。
并且它前瞻性地提醒：`.sheet-handle` 如果顺手加个底色或边框来强调抓手，这条会**立刻**
变成可见的错圆。我这一轮只动了它的 `min-height`（44→48），没动底色，所以不触发。

**B-20**（查了是干净的）：`transition: all` 0 处；过渡里触发重排的属性 0 处；
运行中动画的非 transform/opacity 属性 0 处；未预留尺寸的替换元素 0 处；
长任务 14 次载入里 2 次、均 < 100ms。

## 「app 面不许有工程词」那道闸门本身有两个洞

顺着 A-05（「语义层：离线确定性」出现在老人端「我的」页）查下去，发现闸门报 0 不是
因为干净：

1. **它的脚本清单是手写的**，漏了 `common.js`——一个被**四个 app 页面全部加载**、
   里面装着 `FIELD_LABEL`（六十多条后端字段名到中文的翻译）和一句
   `summary.textContent = '原始响应'` 的文件。也漏了 `identity.js` 和 `sheet.js`。
   改成从 HTML 自己的 `<script src>` 推、再跟着 ES `import` 走一层。
   **补上之后第一次运行就在四个页面上各抓到 3 处**，那些字在屏幕上活了很久。
2. **禁用词名单是从观测到的基线倒推的**，所以只挡得住已经犯过的错。
   「语义」「确定性」「合成」当初没进名单，于是屏幕上写着「语义层：离线确定性」
   而闸门报 0。补了一批按"这个词属于哪一侧的词汇表"选的词，并写清**刻意不收**
   「权限」「授权」的理由（那是安卓/iOS 自己的说法，换掉反而更难找）。

顺带修掉的真泄漏：`common.js` 抛的 `演示登录失败：${role}`——这一句会经
`addBubble('系统暂时不可用：' + e.message)` 念给老人听，整句是
**「系统暂时不可用：演示登录失败：elder」**，一个工程词加一个英文枚举，
两样都是本项目的硬约束明令禁止的。

同类还有 `/trust` 凭证里的 `任务类型 缴费 · 风险级 4 · 意图来源 语义匹配`：
「风险级 4」是裸数字（而 `/family` 早就把 1–4 翻成了「信息查询/低风险/敏感操作/高风险」，
同一件事两页两个名字），「语义匹配」是检索行话，三处兜底还都是 `|| p.<原值>`——
后端返回一个没预料到的枚举就直接把 `embedding` 印在屏幕上。
