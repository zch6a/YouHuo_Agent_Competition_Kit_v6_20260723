# 视觉模式库

这一份记的是**这个项目实际采用的视觉规则**和每一条的理由。和
`INTERACTION_PATTERN_LIBRARY.md`（从参考仓库源码里量出来的交互数字）分开，是因为
那一份是别人的做法，这一份是我们的决定。

数值的唯一定义处是 `backend/static/tokens.css`。这里写的是**为什么**。

最后更新：2026-08-11。

---

## 一、层级靠什么建立

按优先级从高到低。**排在前面的用尽了，才用后面的。**

1. **留白** —— 最强也最便宜。四张卡挤在一起时，加边框不如加间距。
2. **字号与字重** —— `--text-xs` 13 / `--text-sm` 15 / 其余 `clamp()`。
   字重只用 400 / 600 / 700 / 750 / 800。
3. **明度** —— `--ink` / `--ink-2` / `--ink-3` 三级。正文用 `--ink-2`，
   注脚用 `--ink-3`，标题用 `--ink`。
4. **一条 1px 的线** —— `--line` / `--line-strong`。
5. **高程** —— `--shadow-1/2/3`，四段式（近处紧而实、远处宽而淡）。
6. **颜色** —— 最后。而且**从不单独使用**。

第 6 条是硬规则：任何用颜色表达的状态，必须同时有第二个通道。模式切换除了配色，
名字、图标、开场白、音高四样都跟着变；Voice Orb 十一态靠形态区分，颜色只是附带。

参考仓库里量到的一条印证：**没有任何一家把所有标题写成 700**。MD 顶栏标题是 400，
靠字号建立层级。这个项目此前大量 800，已经收敛。

## 二、阴影

```css
--shadow-2:
  0 1px 1px rgba(16, 24, 44, .05),
  0 3px 6px rgba(16, 24, 44, .05),
  0 8px 18px rgba(16, 24, 44, .05),
  0 20px 44px rgba(16, 24, 44, .05);
```

**四段而不是两段。** 真实物体既投一道紧贴的接触影，也投一道很宽很淡的环境影。
两段永远读成"硬投影"或"一团灰污"。近处几乎不透明且极小、远处很宽且极淡——这个比例
才让一张卡看起来是**搁在**页面上，而不是**贴**上去的。

三条相关规则：

- 阴影颜色**不写死**，从令牌派生，深色模式另有一套。`test_design_rulers.py` 守着。
- 白色高光（`rgba(255,255,255,...) inset`）豁免：它不是投影，是受光边。
- 聚焦环和光晕不是高程，不套 `--shadow-*`；它们用 `color-mix` 从主题色算。

新增 `--shadow-pressed`（内阴影，明暗各一版）：方向和上面三级相反，不是浮起来，
是陷进去。只有 Voice Orb 的 `pressed` 态用。

## 三、圆角

`--r-md` / `--r-lg` / `--r-xl` / `--r-2xl`。规则只有一条：**外层圆角必须大于内层**，
否则内层看起来会从外层里"顶"出来。

**但更常见的正确答案是不要嵌套。** 手机上老人端的对话面板和 `#chat` 都不再是卡片
——它们是布局容器，也长得像布局容器。三层同心圆角在 390px 下吃掉 41% 的宽度，
而且是"这是一个网页"最清楚的信号：应用屏是背景加内容，不是卡片里的卡片里的卡片。

---

## 四、间距

4px 网格。`--space-1` 4 到 `--space-16` 64。

收敛之前：194 个字面量，其中 118 个不是 4 的倍数，散布在 2/3/5/6/7/9/10/11/13/14/
15/17/18/22/26 之间。那不是节奏，是一百多个各自拍脑袋定下来又互相不知道的数。

两类豁免，都有理由：流体函数（`clamp` / `calc` / `min` / `env`）内部另核；
大于 64px 的不是间距档位，是页面级尺寸。

**居中用的半像素写成 `calc()`。** 例如时间轴竖线 `left: calc(28px - 1px)`：28 是
序号的半径（在网格上），那 1px 是线宽的一半（不是间距）。写成 `27px` 会被标尺
正确地判为违规。

## 五、触控与命中区

**48×48 是这个项目自己的下限，比 Apple 的 44 高。** 理由是目标用户手抖。
为了省一行版面把它降到 44，是拿手抖的用户换版面。

`min-height` 对行内元素**无效**。`<a>` 和 `<summary>` 默认 `display: inline`，
必须改成 `inline-flex`。这个项目栽过**四次**：首页演示入口、家人端正文里的可信中心
链接、演示舞台的退出链接、凭证的哈希折叠。对比度闸门量出其中一个的命中区是
156×16。

## 六、动效

**动效只能是第二层。** 每一态先要有一副静止形态，动效叠在上面；掐掉动效，
所有状态仍两两可辨。理由和实测见
[`ANTI_PATTERN_LIBRARY.md`](ANTI_PATTERN_LIBRARY.md) 第 1.1 节。

时长档位：

| 用途 | 时长 | 缓动 |
|---|---|---|
| 悬停 / 按下反馈 | 180–200ms | `cubic-bezier(.2,.8,.3,1)` |
| 抽屉进出 | 350ms | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 模式淡出淡入 | `--mode-fade`（~500ms） | ease |
| Voice Orb 呼吸 / 旋转 | 1.6–3.6s | linear / ease-in-out |

弹簧能不能写成 `cubic-bezier()` 只看阻尼比：ζ ≥ 1（不过冲）才行，过冲的要用
`linear()`。iOS 抽屉那条 ζ=4.56 的弹簧数学上要 2280ms，但 349ms 就走完 50% 位移
——诚实的翻译是 350ms，不是 2280ms。

## 七、图标

内联 SVG，`stroke="currentColor"`，`stroke-width` 1.6–2，`aria-hidden="true"`。
重复使用的走外部 sprite（`#icon-*`）。

**不用 emoji 当图标**：emoji 由字体渲染，跨平台形状完全不同，读屏会念出它的
Unicode 名称，而且它没有 `currentColor`——深色模式下不会跟着变。emoji 只出现在
真实的用户内容里。

sprite 有一个隐患：外部 sprite 解析失败时图标是空的，而布局照旧。
`check_sprite_icons` 专门量这一条。

## 八、"这是应用"和"这是网页"的分界

判据不是好不好看，是这几条：

| 应用 | 网页 |
|---|---|
| 一个背景 + 内容 | 卡片里的卡片 |
| 固定的顶栏 / 底栏 / 抽屉 | 长滚动文档 |
| 主控件是唯一的视觉重心 | 五个同等重量的入口 |
| 状态由控件自己表达 | 状态由一行提示文字表达 |
| 定高框架，内部滚动 | 整页滚动 |

老人端全部落在左列。评委页和可信页刻意落在右列——它们是给人读的文档，
按文档的标准做才对。
